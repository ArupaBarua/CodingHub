# CodingHub

This web application, CodingHub focuses on creating a seamless and efficient platform for coding enthusiasts. Solvers can browse and click on problem links that directly navigate them to the problem's website, such as LeetCode, CodeChef, or Codeforces.
Each problem also includes a solution link for reference. Problems are sorted by difficulty—easy, medium, and hard—to help solvers find challenges that match their skill level. Additionally, every solver has a dedicated profile page to track their progress.

Prerequisites to run the project:
- Java Development Kit (JDK) installed (version 8 or higher)
- Apache Maven installed for managing dependencies
- IntelliJ IDEA (or any preferred IDE)
- XAMPP installed (for running the MySQL database and PHPMyAdmin).

Tools used:
- Spring Framework
- MySQL
- Xampp
- Axios
- IntelliJ IDEA
- HTML, CSS, JavaScript
